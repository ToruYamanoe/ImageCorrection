# ニューラルネットワークを用いた屈折異常に対する画像補正

この研究プロジェクトでは、ニューラルネットワークを利用して、屈折異常を持つ人々がより見やすい画像を生成することを目的としています


![image](https://github.com/TorlenBuffet/image_correction/assets/138644618/19210d3a-996c-44fe-a54d-1a82f5e69a70)


利用する画像補正モデルとしては SRCNN, VDSR, UNet などがあります。
PCのスペックに応じてネットワークを選択できますが、これらの中では VDSR が最も深い層を持ち、精度も高いです


## インストール

### 環境構築
依存ライブラリは以下のコマンドで一括インストール可能です。

```bash
pip install -r requirements.txt
```
